# Конструкция try-except-else

> **Главная мысль.** Блок `else` в конструкции `try` выполняется **только если
> в блоке `try` не возникло исключений**. Он размещается после всех блоков
> `except`. Смысл `else` — отделить код, который **может** возбудить
> перехватываемое исключение (он остается в `try`), от кода, который должен
> выполняться только после успешного завершения `try` (он переносится в
> `else`). Исключения, возникшие в `else`, **не перехватываются** блоками
> `except` этой же конструкции, поэтому ошибки в части, зависящей от успеха
> `try`, не маскируются под ожидаемые.

---

## 1. Синтаксис и порядок выполнения

В конструкции `try-except` блок `try` содержит код, в котором может
возникнуть исключение, а блок `except` — реакцию на это исключение. Часто
после успешного выполнения операции необходимо выполнить дополнительные
действия: например, после преобразования строки в число использовать это
число. Такие действия нельзя поместить после всей конструкции без проверки,
потому что при исключении переменная с результатом не будет создана, а
размещение их в конце `try` приводит к тому, что `except` начинает
обрабатывать и исключения из этих действий (см. раздел 2).

Для этого в конструкцию `try` добавляется необязательный блок `else`. Он
записывается после всех блоков `except` и выполняется, если блок `try`
завершился **без исключения**. Если в `try` возникло исключение, блок `else`
пропускается.

Общий вид:

```python
try:
    # код, который может возбудить ожидаемое исключение
    ...

except ExceptionType:
    # обработка исключения
    ...

else:
    # выполняется, только если исключения в try не было
    ...
```

В примере преобразование строки в число находится в `try`, сообщение об
ошибке — в `except`, а использование полученного числа — в `else`:

```python
def parse_age(raw_age: str) -> None:
    try:
        age = int(raw_age)

    except ValueError:
        print("Invalid age")

    else:
        print(f"Age is {age}")


parse_age("42")   # Age is 42
parse_age("abc")  # Invalid age
```

Порядок выполнения:

| Ситуация | try | except | else |
|---|---|---|---|
| Исключения нет | выполнен целиком | пропущен | **выполняется** |
| Исключение есть и перехвачено | прерван на месте исключения | выполняется | пропущен |
| Исключение есть, но не перехвачено | прерван на месте исключения | пропущен | пропущен, исключение распространяется дальше |

Блок `else` допустим **только после хотя бы одного `except`** и обязан
стоять после всех `except`.

---

## 2. Зачем нужен else

Код из `else` можно было бы записать в конце блока `try`. В простых случаях
результат будет одинаковым, но между вариантами есть принципиальное различие:
**исключения из какого кода обрабатывает `except`**.

Сравним два варианта:

```python
# Вариант 1: все в try
try:
    age = int(raw_age)
    print(f"Next year you will be {age + 1}")

except ValueError:
    print("Invalid age")
```

```python
# Вариант 2: преобразование в try, остальное в else
try:
    age = int(raw_age)

except ValueError:
    print("Invalid age")

else:
    print(f"Next year you will be {age + 1}")
```

Предположим, что в части, зависящей от успеха преобразования, возникает
неожиданный `ValueError` (например, из вызываемой функции, внутри которой
есть ошибка):

```python
def calculate_discount(age: int) -> float:
    return float("ten percent")  # ошибка в коде: ValueError


try:
    age = int(raw_age)
    discount = calculate_discount(age)  # ValueError возникнет здесь

except ValueError:
    print("Invalid age")  # неверное сообщение: возраст корректен
```

Ошибка в `calculate_discount` ошибочно принимается за некорректный ввод. При
использовании `else` это исключение не будет перехвачено и проявится как
настоящая ошибка:

```python
try:
    age = int(raw_age)

except ValueError:
    print("Invalid age")

else:
    discount = calculate_discount(age)  # ValueError не перехватывается
```

Блоки `except` обрабатывают **только исключения, возникшие в блоке `try`**.
Исключения, которые возникли в `else`, `except` этой конструкции не
обрабатывает, они распространяются выше.

Правило: в `try` остается **только та операция**, возбуждение исключения в
которой ожидается и для которой известно, как его обработать; все остальное,
что зависит от ее успеха, переносится в `else`.

---

## 3. Когда использовать else

Блок `else` полезен, когда:

- после успешной операции выполняется нетривиальный код, который сам может
  возбудить исключения, не связанные с обрабатываемыми;
- необходимо явно показать, исключения из каких именно строк обрабатывает
  `except`;
- нужно разделить операцию, которая может завершиться неудачей, и
  использование ее результата.

Пример со словарем:

```python
try:
    discount = discounts[category]

except KeyError:
    print("Unknown category")

else:
    final_price = apply_discount(price, discount)
    print(f"Final price: {final_price}")
```

Здесь `except KeyError` обрабатывает исключения только из поиска в словаре.
Если `KeyError` возникнет внутри `apply_discount` из-за ошибки в ее коде, он
не будет принят за неизвестную категорию.

Если же код после `try` ничем не отличается от кода в `try` с точки зрения
перехватываемых исключений, `else` не нужен. Не следует переносить в `else`
код, который не зависит от результата `try`:

```python
try:
    age = int(raw_age)

except ValueError:
    age = 0

print(f"Age is {age}")  # выполняется всегда, else не нужен
```

---

## Вывод

- Блок `else` выполняется, если в `try` **не было исключений**; он
  записывается после всех `except` и допустим только при наличии хотя бы
  одного `except`.
- Блоки `except` обрабатывают **только** исключения, возникшие в `try`.
  Исключения, возникшие в `else`, не перехватываются и распространяются
  дальше.
- В `try` помещают только операцию, возбуждение исключения в которой
  ожидается; код, зависящий от ее успеха, переносят в `else`. Это уменьшает
  риск принять постороннюю ошибку за ожидаемую.
- `else` не нужен, если код после `try` не зависит от успеха операции.
- Порядок частей: `try` → `except` → `else`.
