# Иерархия исключений

> **Главная мысль.** У каждого исключения есть тип (`ValueError`, `KeyError`,
> `ZeroDivisionError` и другие), а типы исключений образуют **иерархию**:
> более общие типы объединяют в себе более частные. Самый общий тип —
> `BaseException`, он включает в себя все остальные. Подавляющее большинство
> исключений, с которыми программист работает ежедневно, входит в группу
> `Exception`. Остальные группы описывают специальные события (выход из
> генератора, прерывание с клавиатуры, завершение программы), а не ошибки
> программы.

---

## 1. Типы исключений и их вложенность

Каждое исключение имеет тип, так же как каждое значение имеет тип (`int`,
`str`, `list`). Тип исключения указывается в сообщении об ошибке, например
`ValueError` или `ZeroDivisionError`.

Типы исключений связаны отношением «входит в»: один тип может входить в другой,
более общий. Например, `ValueError` входит в `Exception`, а `Exception` входит
в `BaseException`. Поэтому любое исключение типа `ValueError` одновременно
считается исключением типа `Exception` и исключением типа `BaseException`.

Обратное неверно: более общий тип не входит в более частный, а типы, не
связанные отношением «входит в», считаются разными. Так, `Exception` не входит
в `ValueError`, а `KeyError` не входит в `IndexError`.

---

## 2. Верхний уровень иерархии

В вершине иерархии находится тип `BaseException`. Непосредственно в него входят
пять типов:

```
BaseException
 ├── Exception            -- обычные исключения
 ├── BaseExceptionGroup   -- группы исключений
 ├── GeneratorExit        -- выход из генератора
 ├── KeyboardInterrupt    -- прерывание с клавиатуры
 └── SystemExit           -- завершение программы
```

Назначение каждого типа:

| Тип | Назначение |
|---|---|
| `Exception` | **Обычные исключения.** Сообщают об ошибках, возникающих при работе программы: некорректные данные, отсутствующие файлы, ошибки в логике. С ними мы работаем большую часть времени |
| `BaseExceptionGroup` | **Группы исключений.** Контейнер, объединяющий несколько исключений в одно (используется при параллельном выполнении задач) |
| `GeneratorExit` | **Выход из генератора.** Возбуждается внутри генератора при вызове его метода `close()` или при уничтожении генератора |
| `KeyboardInterrupt` | **Прерывание с клавиатуры.** Возбуждается, когда пользователь прерывает программу сочетанием клавиш `Ctrl+C` |
| `SystemExit` | **Завершение программы.** Возбуждается функцией `sys.exit()` и означает запрос на выход из процесса |

**В рамках курса мы разбираем только группу `Exception`.** Остальные типы
перечислены для понимания общей картины.

---

## 3. Почему группа Exception выделена отдельно

Три специальных типа (`GeneratorExit`, `KeyboardInterrupt`, `SystemExit`)
входят в `BaseException`, но не входят в `Exception`, **намеренно**. Они
сообщают не об ошибке в программе, а о событии, которое должно приводить к
завершению работы или к выходу из текущего контекста:

- пользователь нажал `Ctrl+C` — он хочет остановить программу;
- вызван `sys.exit()` — программа сама решила завершиться;
- генератор закрыт — его работа закончена.

Такое разделение позволяет отличать ошибки программы (группа `Exception`) от
событий, управляющих ее работой (остальные типы).

---

## 4. Устройство группы Exception

`Exception` включает в себя большое число типов. Исключения, которые
встречаются чаще всего, образуют иерархию:

```
Exception
 ├── ArithmeticError
 │    ├── ZeroDivisionError
 │    └── OverflowError
 ├── LookupError
 │    ├── IndexError
 │    └── KeyError
 ├── OSError
 │    ├── FileNotFoundError
 │    ├── PermissionError
 │    └── FileExistsError
 ├── ValueError
 ├── TypeError
 ├── AttributeError
 ├── NameError
 └── ...
```

Показана лишь малая часть иерархии. Полную схему можно найти в
[документации](https://docs.python.org/3/library/exceptions.html#exception-hierarchy).

Типы `ArithmeticError`, `LookupError` и `OSError` объединяют исключения по
смыслу:

- `ArithmeticError` — ошибки арифметических операций;
- `LookupError` — ошибки поиска элемента по индексу или ключу;
- `OSError` — ошибки взаимодействия с операционной системой, в том числе при
  работе с файлами.

Вложенность на схеме читается так: `ZeroDivisionError` входит в
`ArithmeticError`, `KeyError` и `IndexError` входят в `LookupError`,
`FileNotFoundError` входит в `OSError`. Типы, расположенные на одном уровне
(например, `KeyError` и `IndexError`), друг в друга не входят.

Чем ближе тип к вершине иерархии, тем **шире** группа исключений, которую он
объединяет, и тем меньше информации о причине ошибки. Тип `Exception` включает
в себя практически все ошибки программы, а `ZeroDivisionError` описывает только
деление на ноль.

## Вывод

- У каждого исключения есть тип. Типы исключений образуют иерархию: более
  общий тип включает в себя более частные. Самый общий тип — `BaseException`.
- Непосредственно в `BaseException` входят пять типов: `Exception` (обычные
  исключения), `BaseExceptionGroup` (группы исключений), `GeneratorExit`
  (выход из генератора), `KeyboardInterrupt` (прерывание с клавиатуры),
  `SystemExit` (завершение программы).
- Три последних специальных типа не входят в `Exception`, потому что
  сообщают о событиях, а не об ошибках программы.
- В курсе разбирается только группа `Exception`.
- Типы `ArithmeticError`, `LookupError` и `OSError` объединяют исключения по
  смыслу. Чем ближе тип к вершине иерархии, тем шире группа исключений, которую
  он включает.
