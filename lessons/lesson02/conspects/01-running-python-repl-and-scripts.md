# Запуск программ на Python: REPL и запуск скриптов

> **Главная мысль.** Чтобы выполнить код на Python, нужна программа-интерпретатор
> (`python`). Пользоваться ей можно двумя способами: вводить команды по одной в
> интерактивном режиме (**REPL**) или отдать интерпретатору целый файл со
> скриптом, и он выполнит его от начала до конца.

---

## 1. Интерпретатор — это программа

Когда мы устанавливаем Python, на компьютере появляется исполняемый файл —
интерпретатор. Обычно он называется `python` (в некоторых системах — `python3`).
Именно эта программа умеет читать текст, написанный по правилам языка Python, и
выполнять его.

Проверить, что интерпретатор установлен и какой он версии, можно с помощью следующей команды:

```console
$ python --version
Python 3.12.4
```

У интерпретатора есть два основных режима работы:

- **интерактивный режим (REPL)** — диалог: вы вводите одну команду, интерпретатор
  сразу ее выполняет и показывает результат;
- **пакетный режим (запуск скрипта)** — вы сообщаете интерпретатору путь до файла с расширением `.py`,
  и он выполняет код из этого файла.

---

## 2. Интерактивный режим: REPL

**REPL** — это аббревиатура от **R**ead – **E**val – **P**rint – **L**oop
(«прочитать – вычислить – напечатать – повторить»). Название описывает цикл, в
котором работает интерактивный режим:

1. **Read** — прочитать строку, которую ввел пользователь;
2. **Eval** — вычислить ее (выполнить);
3. **Print** — напечатать результат;
4. **Loop** — вернуться к шагу 1 и ждать следующую строку.

### Как запустить

Запустите `python` без аргументов:

```console
$ python
Python 3.12.4 (main, Jun  7 2024, 19:23:07) [GCC 13.2.0] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>>
```

Приглашение `>>>` означает «жду команду». Приглашение `...` появляется, когда
интерпретатор ждет продолжения многострочной конструкции.

### Что умеет REPL

Выводит значение выражения даже без использования встроенной функции `print()`:

```pycon
>>> 2 + 3
5
>>> "abc" * 3
'abcabc'
>>> len("Python")
6
```

Сохраняет результат последних вычислений в переменную `_`:

```pycon
>>> 10 * 5
50
>>> _ + 1
51
```

Умеет работать с многострочными конструкциями. После двоеточия появляется приглашение
`...`; чтобы завершить блок, вводят пустую строку:

```pycon
>>> if 3 > 2:
...     print("greater")
...
greater
```

Позволяет получить быстрый доступ к справочной информации:

```pycon
>>> help(len)
>>> dir(str)          # список методов строк
```

### Как выйти из REPL

- вызвать функцию `exit()` или `quit()`;
- нажать `Ctrl-Z`, затем `Enter` (Windows) или `Ctrl-D` (Linux/macOS).

### Для чего REPL хорош, а для чего нет

| Хорош для | Плохо подходит для |
|---|---|
| быстрых экспериментов: «а что вернет эта функция?» | больших программ — код нигде не сохраняется |
| проверки поведения оператора или метода | того, что нужно запускать повторно |
| изучения незнакомых объектов (`type`, `dir`, `help`) | командной работы (нечего положить в репозиторий) |

## 3. Пакетный режим: запуск скрипта

Настоящие программы хранят в файлах с расширением `.py`. Создадим файл
`hello.py` со следующим содержимым:

```python
name = input("Enter your name: ")
print(f"Hello, {name}!")
```

Запуск:

```console
$ python hello.py
Enter your name: Mike
Hello, Mike!
```

Что происходит: интерпретатор открывает файл, обрабатывает **все** его содержимое, после чего 
последовательно выполняет инструкции. В отличие от REPL, значение выражения не выводится на экран само по себе. 
Если результат необходимо напечатать в стандартный поток вывода, это делается явно с помощью
встроенной функции `print()`.

```python
2 + 3            # в скрипте результат выполнения этой строки не будет напечатан
print(2 + 3)     # выведет 5 в стандартный поток вывода
```

---

## 4. Полезные способы запуска

| Команда | Что делает |
|---|---|
| `python script.py` | выполнить файл-скрипт |
| `python` | запустить REPL |
| `python -c "print(2 + 3)"` | выполнить код прямо из строки команды |
| `python -m http.server` | запустить модуль из стандартной библиотеки как программу |
| `python -i script.py` | выполнить скрипт и **остаться** в REPL с его переменными |

Пример с `-i` удобен для отладки: скрипт отработал, а вы можете руками
посмотреть, что осталось в переменных.

## 5.  `.pyc` и  `__pycache__`

После первого запуска скрипта, который импортирует ваши модули, рядом появляется
папка `__pycache__` с файлами `.pyc`. Это **кэш скомпилированного байткода** —
промежуточного представления программы, которое интерпретатор готовит перед
выполнением.

Появление `.pyc` — хороший повод задать следующий вопрос: **что именно
интерпретатор делает с текстом программы, прежде чем ее выполнить?** Этому
посвящена [следующая часть](./02-how-the-interpreter-runs-a-program.md) конспекта.
