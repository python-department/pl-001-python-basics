# Объекты: идентичность, тип данных и значение

> **Главная мысль.** Любые данные в Python-программе представлены **объектами**.
> У каждого объекта есть три характеристики: **идентичность** (кто он —
> неизменный «адрес»), **тип данных** (что он такое и что с ним можно делать) и
> **значение** (какие данные он хранит). Идентичность и тип данных неизменны на протяжении всей жизни
> объекта, а вот значение — меняется или нет в зависимости от того, **изменяемый**
> (mutable) или **неизменяемый** (immutable) тип данных данного объекта.

---

## 1. Все — объект

Сложно представить себе программу, которая не занимается манипуляциями с данными. 
В этом смысле Python-программы не являются исключениями. Для представления данных 
в Python используется специальная абстракция — **Python-объект**, или просто объект (object).

Любые данные, с которыми вы работаете в Python-программах, будут представлены в виде объектов.

У каждого объекта есть три характеристики — идентичность, тип данных и значение. Разберем
их по порядку, а затем, в разделе 6, вернемся к вопросу о том, как с этими объектами
соотносятся переменные.

---

## 2. Идентичность (identity)

**Идентичность** — признак, который отличает объект от всех остальных и
**не меняется** за все время его существования.

Идентичность объекта можно получить с помощью встроенной функции `id()`, которая
возвращает идентичность в виде целого числа. В CPython результатом выполнения функции
`id()` является адрес объекта в памяти.

```python
a = [1, 2, 3]
b = a
c = [1, 2, 3]        # отдельный объект с таким же значением

print(id(a), id(b))  # одинаковые: одно и то же
print(id(a) == id(c))  # False: разные объекты
```

Оператор `is` позволяет сравнивать **идентичности** объектов, оператор `==` — их **значения**:

```python
a is b      # True  — один и тот же объект
a is c      # False — разные объекты
a == c      # True  — но значения равны
```

> **Правило.** `==` — «равны ли данные?». `is` — «это буквально один объект?».
> С `None` всегда используют `is`: `if x is None:`.

### Осторожно: кэширование мелких объектов

CPython переиспользует некоторые неизменяемые объекты (маленькие целые −5…256,
короткие строки), поэтому `is` для них может неожиданно вернуть `True`. Это деталь
реализации, полагаться на нее в программах не следует:

```python
x = 256
y = 256
print(x is y)      # True  — но это оптимизация CPython, не гарантия языка

x = 1000
y = 1000
print(x is y)      # часто False
```

## 3. Тип данных (type)

**Тип данных** определяет две вещи: какие **значения** объект может представлять и какие
**операции** с ним допустимы. Тип данных объекта задается при создании и **не меняется**.

Тип данных объекта можно получить с помощью вызова встроенного объекта `type()` — он возвращает
объект-тип (класс), к которому принадлежит переданный объект. Чтобы проверить, относится
ли объект к определенному типу данных (или к одному из его подклассов), удобнее пользоваться
встроенной функцией `isinstance(объект, тип)` — она возвращает `True` или `False`, не
заставляя сравнивать результат `type()` вручную.

```python
n = 10
print(type(n))              # <class 'int'>
print(isinstance(n, int))   # True

n = "теперь строка"         # объект не «сменил тип данных» — имя n просто привязали
print(type(n))              # <class 'str'>   к другому объекту, уже строковому
```

Тип данных диктует поведение операторов:

```python
2 + 3          # 5     — для int это сложение
"2" + "3"      # '23'  — для str это склейка
[1] + [2]      # [1, 2] — для list это конкатенация
"2" + 3        # TypeError — типы несовместимы, неявного приведения нет
```

## 4. Значение (value)

**Значение** — это данные, которые объект хранит: число `42`, символы строки,
элементы списка.

Может ли значение меняться — зависит от типа данных.

---

## 5. Изменяемые и неизменяемые типы

Типы данных объектов делятся на две группы: изменяемые и неизменяемые.
От того, является ли тип данных объекта изменяемым или нет, зависит возможность изменения
значения этого объекта в процессе выполнения программы.

### Неизменяемые (immutable)

Если тип данных объекта является неизменяемым, после создания значение этого объекта
**изменить нельзя**. Любая модификация этого объекта на самом деле создает **новый**
объект и перепривязывается к нему имя исходного объекта.

Неизменяемыми типами данных являются: `int`, `float`, `complex`, `bool`, `str`, `bytes`, `tuple`,
`frozenset`, `None`.

### Изменяемые (mutable)

Если тип данных объекта является изменяемым, значение этого объекта можно менять **на месте**:
идентичность и тип данных остаются прежними, меняется только содержимое.

Изменяемыми типами данных являются: `list`, `dict`, `set`, `bytearray`, а также обычные экземпляры
классов.

## 6. Переменные и ссылки

Теперь, когда мы познакомились с идентичностью, типом данных и значением объекта, можно
разобраться, как с объектами соотносятся переменные.

**Переменная — это не объект, а имя (ссылка, ярлык), которое хранится в пространстве
имен и указывает на объект, живущий в памяти.** Это отличается от модели C-подобных
языков, где переменная — «коробка», в которую кладут значение. В Python имя не
«содержит» объект, а лишь ссылается на него — как стикер, который можно переклеить
на другой предмет.

```python
a = [1, 2, 3]
b = a               # НЕ копия: b — второе имя того же объекта в памяти
```

### Присваивание — это связывание (binding)

В Python операция `=` не обозначает «положить значение в переменную», а является операцией
**связывания (binding)**: имя связывается со ссылкой на объект, который либо уже
существует в памяти, либо создается прямо сейчас. Переменная нигде заранее не
объявляется — при связывании имя просто появляется в пространстве имен
и получает ссылку на объект.

```python
x = 42
```

Здесь происходит следующее:

1. создается объект `42` типа `int` (если такого объекта еще не существует);
2. имя `x` появляется в пространстве имен;
3. имя `x` связывается со ссылкой на этот объект.

### Новый объект или привязка к существующему

Важно различать два исхода одной и той же операции связывания:

- **создается новый объект** — если объекта с нужным значением еще нет, интерпретатор
  выделяет под него память и связывает имя с этим новым объектом;
- **имя привязывается к уже существующему объекту** — если подходящий объект уже есть
  (например, на него ссылается другое имя), новый объект не создается — имя получает
  ссылку на тот же самый объект.

```python
a = [1, 2, 3]     # создается новый объект-список
b = a             # НЕ новый объект: b получает ссылку на тот же объект, что и a
b = [1, 2, 3]     # создается новый объект-список
```

### Перепривязка (rebinding)

Когда имя, уже связанное с одним объектом, связывают с другим объектом, происходит
**перепривязка (rebinding)**: имя просто начинает ссылаться на другой объект, а
прежний объект при этом никак не меняется (и будет уничтожен сборщиком мусора, если
ссылок на него больше не осталось).

```python
x = 42          # x привязан к объекту 42
y = x           # y привязан к тому же объекту, что и x
x = "hello"     # ПЕРЕПРИВЯЗКА: x теперь ссылается на новый объект "hello"

print(x)        # hello
print(y)        # 42 — y по-прежнему ссылается на прежний объект, он не изменился
```

`x = "hello"` не изменило объект `42` и не «превратило» его в строку — идентичность
и тип данных объекта неизменны (см. разделы 2 и 3), изменить их в принципе невозможно.
Вместо этого имя `x` просто перепривязали к другому объекту — старый объект как был,
так и остался объектом `42`, просто на него больше нет ссылки по имени `x`.

## Вывод

- Данные в программе — это **объекты**.
- У объекта три характеристики:
  - **идентичность** — `id(obj)`, сравнивается через `is`, **неизменна**;
  - **тип данных** — `type(obj)`, задает допустимые операции, **неизменен**;
  - **значение** — сами данные, `==` сравнивает именно его.
- **Неизменяемые** типы (`int`, `str`, `tuple`, …): значение зафиксировано,
  «изменение» = новый объект.
- **Изменяемые** типы (`list`, `dict`, `set`, …): значение можно менять на месте.
- Переменные — лишь **имена**, привязанные к объектам. `=` — это не присваивание
  значения переменной, а **связывание (binding)** имени со ссылкой на объект. Если
  подходящего объекта еще нет — создается новый; если уже есть — имя привязывается
  к нему без создания нового объекта.
- Если имя, уже связанное с объектом, связывают с другим объектом — это
  **перепривязка (rebinding)**: старый объект не меняется, меняется лишь то, на что
  ссылается имя.
