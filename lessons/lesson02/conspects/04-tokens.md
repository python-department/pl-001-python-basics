# Токены: из чего состоит строка кода

> **Главная мысль.** Во время парсинга интерпретатор сначала разбивает текст
> программы на **токены** — минимальные значимые «кирпичики». Токенов пять видов:
> **идентификаторы**, **ключевые слова**, **литералы**, **операторы** и
> **разделители**. Пробелы между токенами интерпретатор отбрасывает, а отступы
> превращает в отдельные токены `INDENT` / `DEDENT`.

---

## Что такое токен

**Токен** (лексема) — это неделимая единица текста программы, у которой есть
тип и значение. Токенизация похожа на то, как мы читаем предложение: делим
поток символов на слова и знаки препинания и сразу понимаем роль каждого куска.
Аналогично, для интерпретатора «сырой» символ, например, `=` ничего не значит до тех пор, пока
токенизатор не пометит его как оператор (`OP`). И только после этого с ним сможет 
работать парсер.

Возьмем строку:

```python
total = price * 2  # с наценкой
```

Токенизатор превращает ее в такой поток токенов:

| Текст | Тип токена |
|---|---|
| `total` | идентификатор |
| `=` | оператор |
| `price` | идентификатор |
| `*` | оператор |
| `2` | литерал (число) |
| `# с наценкой` | комментарий (отбрасывается) |
| конец строки | `NEWLINE` |

Пытливые умы могут посмотреть разбор самостоятельно с помощью модуля стандартной 
библиотеки `tokenize`.

## 1. Идентификаторы

**Идентификатор** — имя, которое программист связывает с объектом: переменной,
функцией, классом, модулем, аргументом. 
Идентификаторы используются для простоты повторного обращения к одним и тем же данным.

Примеры идентификаторов:

```python
price = 100                            # price — имя переменной
def calculate_total(items): ...        # calculate_total — имя функции, items — имя аргумента
class BankAccount: ...                 # BankAccount — имя класса
```

Правила именования:

- идентификатор может состоять из букв, цифр и подчеркивания `_`;
- идентификатор не может начинаться с цифры: `2fast` — ошибка, `fast2` — можно;
- идентификаторы чувствительны к регистру: `total`, `Total` и `TOTAL` — три разных имени;
- нельзя использовать ключевые слова в качестве идентификаторов.

### Соглашения о стиле имен

Интерпретатору все равно, как выглядит имя, — код с `MyVariable` и `myVariable`
отработает одинаково. Однако в python-сообществе есть определенные правила именования, закрепленные в
[PEP 8](https://peps.python.org/pep-0008/#naming-conventions). Этих правил стоит придерживаться для увеличения 
читаемости вашего кода: другому Python-разработчику будет легче понимать ваш код, если вы соблюдаете 
общие правила именования сущностей.

Общие правила именования:

| Что именуем | Стиль | Пример |
|---|---|---|
| переменные, функции, методы, аргументы | `snake_case` | `total_price`, `calculate_total`, `items` |
| модули и пакеты | короткий `snake_case` (пакеты — лучше без `_`) | `utils.py`, `json`, `mypackage` |
| классы | `PascalCase` | `BankAccount`, `HttpClient` |
| константы (уровень модуля) | `UPPER_SNAKE_CASE` | `MAX_RETRIES`, `PI` |

## 2. Ключевые слова

**Ключевые слова** — зарезервированные имена, у которых в языке фиксированный
смысл. Их нельзя переопределять.

```python
import keyword
print(keyword.kwlist)
```

```
['False', 'None', 'True', 'and', 'as', 'assert', 'async', 'await', 'break',
 'class', 'continue', 'def', 'del', 'elif', 'else', 'except', 'finally', 'for',
 'from', 'global', 'if', 'import', 'in', 'is', 'lambda', 'nonlocal', 'not', 'or',
 'pass', 'raise', 'return', 'try', 'while', 'with', 'yield']
```

Попытка использовать ключевое слово как имя приведет к исключению `SyntaxError`:

```python
class = 10
# SyntaxError: invalid syntax
```

> Начиная с версии Python 3.10 в языке появились **мягкие ключевые слова** (`match`, `case`, `type`, `_`): они особые
> только в определенном контексте, а в остальном могут использоваться в качестве идентификаторов.

## 3. Литералы

**Литерал** — запись значения прямо в коде. При
исполнении кода из литерала создается объект с указанным значением.

```python
42                 # целое число              (int)
3.14               # число с плавающей точкой (float)
2 + 3j             # комплексное число        (complex)
"привет"           # строка                   (str)
b"bytes"           # байтовая строка          (bytes)
True  False        # логические значения      (bool)
None               # «ничего»                 (NoneType)
```

Списки, словари и кортежи задаются не одним токеном, а конструкцией из
разделителей и других токенов:

```python
[1, 2, 3]          # литерал списка: [ , , ]  + числовые литералы
{"a": 1}           # литерал словаря
(1, 2)             # литерал кортежа
```

## 4. Операторы

**Операторы** — символы операций над значениями.

| Группа | Токены |
|---|---|
| Арифметические | `+  -  *  **  /  //  %` |
| Сравнение | `<  >  <=  >=  ==  !=` |
| Битовые | `&  \|  ^  ~  <<  >>` |
| Составное присваивание | `+=  -=  *=  **=  /=  //=  %=  &=  \|=  ^=  <<=  >>=  @=` |
| Присваивание-выражение («морж») | `:=` |
| Прочие | `.` — доступ к атрибуту, `@` — матричное умножение |

```python
result = 2 ** 10        # ** — возведение в степень
count += 1              # += — прибавить и присвоить
is_ready = a < b        # < — сравнение, дает bool
```

Логические `and`, `or`, `not` и операторы принадлежности и тождества `in`, `is` —
это **ключевые слова**, хотя, фактически, выполняют роль операторов.

> **Оператор или разделитель?** [Справочник языка](https://docs.python.org/3/reference/lexical_analysis.html#operators-and-delimiters)
> объединяет операторы и разделители в один тип токена — `OP` — и прямо
> оговаривает, что формальной границы между ними нет. Один и тот же символ бывает
> и тем, и другим: `*` — умножение и распаковка, `@` — матричное умножение и
> декоратор, `.` — доступ к атрибуту и просто разделитель. Три точки подряд
> `...` — это токен `OP`, но по смыслу литерал `Ellipsis`.

## 5. Разделители

**Разделители** (delimiters) — символы, которые структурируют код: группируют и
разделяют элементы, обозначают конструкции.

```
(  )  [  ]  {  }     скобки: вызовы, группировка, кортежи, списки, множества, словари
,                    разделяет элементы: аргументы, элементы коллекций
;                    разделяет несколько инструкций в одной строке
:                    срезы, словари, аннотации, начало тела блока
=                    присваивание и передача именованного аргумента
->                   аннотация возвращаемого типа функции
!                    конверсия значения в f-строке: f"{value!r}"
```

Символы `@` (декоратор) и `.` (доступ к атрибуту) в грамматике языка
отнесены к операторам, но по роли это тоже разделители — тип токена у них общий,
`OP`.

## Как токены участвуют в разборе

```
текст программы
      │  токенизатор
      ▼
поток токенов:  NAME '=' NAME '*' NUMBER NEWLINE  INDENT ... DEDENT
      │  парсер проверяет порядок по грамматике
      ▼
дерево AST → байткод → исполнение
```

Если токены идут в недопустимом порядке (`2 = x`, `if if`, незакрытая скобка) —
парсер выдает `SyntaxError` еще до запуска программы.

## Вывод

| Вид токена | Что это | Примеры |
|---|---|---|
| **Идентификатор** | имя, данное программистом | `price`, `calculate_total`, `BankAccount` |
| **Ключевое слово** | зарезервированное слово языка | `if`, `for`, `def`, `return`, `True`, `None` |
| **Литерал** | значение, записанное в коде | `42`, `3.14`, `"текст"`, `True`, `None` |
| **Оператор** | символ операции | `+`, `**`, `==`, `+=`, `:=`, `@` |
| **Разделитель** | структурный символ | `( )`, `[ ]`, `{ }`, `,`, `;`, `:`, `=`, `->`, `!` |
