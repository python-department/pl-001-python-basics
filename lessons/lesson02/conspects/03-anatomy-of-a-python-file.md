# Анатомия Python-файла: строки, инструкции, отступы

> **Главная мысль.** Программа на Python хранится в текстовом файле. Текст делится
> на **физические строки**, которые собираются в **логические строки**. Логическая
> строка содержит команду — **инструкцию** или **выражение**. Инструкции бывают
> **простые** и **составные**. Еще строки бывают пустыми или комментариями. У
> каждой строки есть **уровень отступа**, и он влияет на смысл программы.

---

## 1. Python-файл — это просто текст

Файл с расширением `.py` — обычный текстовый файл в кодировке UTF-8. Его можно открыть в любом текстовом
редакторе.

Однако, файлы с расширением `.py` не могут содержать произвольный текст. Одна из ключевых особенностей Python, 
которая бросится вам в глаза в первую очередь — строки и отступы. В Python **пробелы и переводы строк — 
значимые символы**. Нельзя, например, как в C или JavaScript, произвольно расставлять переносы и
отступы для красоты, т.к. интерпретатор учитывает их во время парсинга и компиляции.

---

## 2. Физические строки

**Физическая строка** — это последовательность символов до символа конца строки
(того, что появляется, когда вы нажимаете Enter).

В данном примере код содержит три физических строки:

```python
x = 1
y = 2
z = 3
```

---

## 3. Пустые строки и комментарии

Существуют следующие виды физических строк и их частей, которые игнорируются интерпретатором:

- **Пустые строки** — строки, содержащие только символ новой строки или символы табуляции. 
Пустые строк используют, чтобы визуально разделить смысловые части кода.

- **Комментарии** — последовательности символов, которые начинаются с символа `#`. Комментарий 
не обязательно должен находиться в отдельной физической строке, нередко комментарии располагают 
в конце физической строки в качестве пояснений к коду.

Примеры комментариев:

```python
# Считаем итоговую цену с налогом
price = 100          # базовая цена
tax = price * 0.2    # налог 20%
total = price + tax
```

Символ `#` внутри строкового литерала комментарием **не** является:

```python
url = "https://example.com/#section"   # это часть строки, а не комментарий
```

Несмотря на то, что пустые строки и комментарии игнорируются интерпретатором, не стоит пренебрегать 
их использованием. Разумное использование пустых строк и комментариев сделает ваш код 
более читаемым и понятным для других разработчиков.

## 4. Логические строки

**Логическая строка** — это последовательность символов, которую интерпретатор воспринимает как одну команду.
Нередко одна логическая строка соответствует одной физической. Однако существуют исключения в обе
стороны.

### 4.1. Несколько физических строк → одна логическая

Бывают ситуации, когда одну логическую строку полезно разбить на несколько физических. 
Такие ситуации возникают, когда исходная строка слишком длинная и занимает очень много 
места на вашем экране.

Один из способов разбиения логической строки на несколько физических пришел в 
Python из С: использование символа обратный слеш `\` в конце строки.

```python
total = price + \
        tax - \
        discount
```

В этом случае Python воспринимает все три физические строки, как часть одной команды.

Однако подход с использованием `\` считается устаревшим и некрасивым, а потому редко 
используется на практике. Более того, значительная часть линтеров и форматеров будут 
считать использование этого подхода нарушением принципов написания Python-кода.

Более предпочтительным подходом к разбиению логических строк на физические является 
использование скобок `()`, `[]`, `{}`. Содержимое, заключенное между скобками одного 
и того же типа, считается одной логической строкой, даже если оно занимает более одной 
физической строки.

Пары скобок `[]` и `{}` используются для разбиения на несколько физических строк определений 
конкретных типов коллекций. Пара скобок `()` может использоваться вне контекста коллекций.

```python
numbers = [
    1, 2, 3,
    4, 5, 6,
]

total = (price
         + tax
         - discount)
```

Использование скобок для разбиения логических строк — это рекомендуемый подход.

### 4.2. Несколько логических строк → одна физическая

Через точку с запятой `;` можно записать несколько простых инструкций в одну
физическую строку:

```python
x = 1; y = 2; z = 3
```

Так делать не рекомендуется, т.к. такой способ оформления кода менее читаемый.

## 5. Что содержит строка: инструкции и выражения

Команды в Python делятся на выражения и инструкции.

### Выражение (expression)

**Выражение** — это команда, выполнение которой приводит к вычислению некоторого значения.

В данном листинге кода приведены примеры выражений в Python:

```python
2 + 2            # арифметическое выражение (операторы) → int 4
price * 1.2      # арифметическое выражение с переменной → float (цена с наценкой)
len("Python")    # выражение-вызов функции → int 6 (длина строки)
max(a, b)        # выражение-вызов функции с аргументами → большее из значений a и b
"строка"         # литерал — простейшее выражение, вычисляется сам в себя → str "строка"
user.name        # выражение доступа к атрибуту объекта → значение поля name у user
```

Выражение всегда вычисляет некоторое значение. Выражения можно использовать там, где
ожидается некоторое значение: справа от оператора `=`, в аргументе функции, в условии `if`.

Выражения являются частным случаем инструкций.

### Инструкция (statement)

**Инструкция** — это команда, которую может выполнить компьютер. Выполнение инструкции 
меняет состояние программы, управляет ходом ее выполнения. Выражения являются частным случаем инструкций, 
но не наоборот, поскольку не все инструкции вычисляют некоторые значения в результате выполнения.

Примеры инструкций:

```python
x = 10            # привязка
import math       # импорт модуля
return result     # возврат значения из функции
if x > 0: ...     # ветвление
```

## 6. Простые и составные инструкции

Все инструкции в Python делятся на простые и составные.

### Простые инструкции (simple statements)

Простые инструкции — это инструкции, которые состоят из одной логической строки. Примеры:

```python
x = 42                 # привязка
x += 1                 # составное присваивание
del x                  # удаление имени
pass                   # «пустая инструкция»
import math            # импорт модуля
assert x > 0           # отладочная проверка
return x               # возврат значения из функции
break                  # выход из цикла
```

Самая частая простая инструкция — привязка.

### Составные инструкции (compound statements)

Составные инструкции — это инструкции, которые состоят более чем из одной логической строки. 
Составные инструкции обычно используются для управления потоком выполнения программы.

Составные инструкции из **заголовка** (строка с ключевым словом, заканчивается двоеточием `:`) 
и **тела** — блока вложенных инструкций с увеличенным отступом.

Примеры составных инструкций:

```python
# ветвление
if temperature > 30:        # заголовок
    print("too hot")        # тело (блок)
    turn_on_air()

# цикл for
for item in cart:           # заголовок
    print(item)             # тело
```

## 7. Отступы (indentation)

В большинстве языков программирования блоки кода заключают в фигурные скобки или в 
специальную пару инструкций начала и конца блоков кода, а отступы —
дело вкуса. **В Python отступ — часть синтаксиса.** Именно он определяет, какие
инструкции входят в тело составной инструкции, а какие — нет.

```python
if user.is_active:
    send_email(user)       # входит в if (отступ 4)
    log("email sent")      # входит в if (отступ 4)
cleanup()                  # НЕ входит в if (отступ 0) — выполнится всегда
```

Правила:

- увеличение отступа открывает новый блок, возврат к прежнему уровню отступа — закрывает его;
- внутри одного блока кода у всех строк отступ **одинаковый**; рассогласование —
  `IndentationError`;
- **нельзя смешивать пробелы и табуляцию** для отступов — это приведет к ошибке `TabError`;
- стандарт (PEP 8) — **4 пробела** на уровень.

Во время токенизации переходы между уровнями отступа превращаются в невидимые
токены `INDENT` и `DEDENT` — по сути, в аналог открывающей и закрывающей скобки.

```python
# Один и тот же текст, разные отступы — разный смысл:

# Вариант А: print внутри цикла
for i in range(3):
    print(i)
    print("---")

# Вариант Б: второй print уже вне цикла
for i in range(3):
    print(i)
print("---")
```

## Вывод

- Файл `.py` — текст из **физических строк**; значимы переводы строк и пробелы.
- Строки бывают **пустыми**, также строки могут содержать **комментарии**. Пустые строки
  и комментарии игнорируются интерпретатором.
- Физические строки формируют **логические строки** — строки, содержащие команды: 
  **выражения** или **инструкции**.
- Инструкции бывают **простые** (состоят из одной логической строки) и
  **составные** (состоят более чем из одной логической строки).
- **Отступ** в Python — часть синтаксиса: он задает границы блоков кода. Стандарт —
  4 пробела, смешивать с табами нельзя.
