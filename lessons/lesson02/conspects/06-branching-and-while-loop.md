# Управляющие конструкции: ветвление и цикл `while`

> **Главная мысль.** `if` и `while` — **составные инструкции**: заголовок с
> ключевым словом и условием, двоеточие, затем вложенный блок с увеличенным
> отступом. Условие — это **выражение**, значение которого интерпретатор
> проверяет на истинность. `if` выполняет блок **один раз, если** условие
> истинно; `while` повторяет блок **пока** условие истинно.
---

## 1. Форма составной инструкции

```
КЛЮЧЕВОЕ_СЛОВО  условие :
    инструкция_1
    инструкция_2
```

- **заголовок** — строка с ключевым словом (`if`, `while`, `elif`, `else`),
  условием и **двоеточием** `:` в конце;
- **тело (блок)** — одна или несколько инструкций с **одинаковым увеличенным
  отступом** (стандарт — 4 пробела);
- возврат к прежнему отступу закрывает блок.

При токенизации начало блока — это токен `INDENT`, конец — `DEDENT`; двоеточие —
разделитель, ключевое слово — токен-keyword.

---

## 2. Истинность условия

Условие — любое **выражение**. Интерпретатор вычисляет его в объект и приводит к
логическим объектам `True` или `False` по правилам **проверки истинности**:

**Ложны** (falsy):

```python
False
None
0        0.0      0j                 # нулевые значения
""       ""                          # пустая строка
[]       {}       set()      ()      # пустые контейнеры
```

**Истинно** (truthy) — все остальное: любое ненулевое число, любая непустая
строка или контейнер.

```python
if "":
    print("не выполнится")     # пустая строка ложна

if [0]:
    print("выполнится")        # список из одного элемента — непустой, истинен
```

---

## 3. Ветвление

Ветвление нужно, чтобы программа выполняла разный код в зависимости от
условия — например, в зависимости от ввода пользователя, состояния данных или
результата вычисления. Реализуется ветвление инструкцией `if`, у которой есть
несколько вариантов: только `if`, `if`/`else` и `if`/`elif`/`else`.

### Только `if`

Блок выполняется, если условие истинно, иначе пропускается.

```python
temperature = 35

if temperature > 30:
    print("Жарко")
    print("Включите кондиционер")

print("Конец")     # отступ 0 — вне if, выполнится всегда
```

### `if` / `else`

Одна из двух веток выполнится обязательно.

```python
number = 7

if number % 2 == 0:
    print("четное")
else:
    print("нечетное")
```

### `if` / `elif` / `else`

Проверки идут сверху вниз; выполняется блок **первого** истинного условия,
остальные пропускаются. `else` — необязательный, срабатывает, если ни одно
условие не подошло.

```python
score = 78

if score >= 90:
    grade = "отлично"
elif score >= 75:
    grade = "хорошо"
elif score >= 60:
    grade = "удовлетворительно"
else:
    grade = "неудовлетворительно"

print(grade)      # хорошо
```

### Вложенность

Внутри блока может быть другая составная инструкция — с еще большим отступом:

```python
if user.is_authenticated:
    if user.is_admin:
        show_admin_panel()
    else:
        show_dashboard()
else:
    show_login()
```

## 4. Цикл `while`

Цикл while нужен, когда заранее неизвестно, сколько раз повторить действие —
известно лишь условие, при котором нужно продолжать. Например: повторять
запрос ввода, пока пользователь не введет корректное значение, или делить
число, пока оно не станет равным нулю. `while` повторяет тело **пока**
условие истинно. Порядок работы:

1. вычислить условие;
2. если ложно — выйти из цикла;
3. если истинно — выполнить тело и вернуться к шагу 1.

```python
count = 1

while count <= 5:
    print(count)
    count += 1        # ОБЯЗАТЕЛЬНО меняем то, от чего зависит условие

print("Готово")
```

```
1
2
3
4
5
Готово
```

### Бесконечный цикл

Если условие никогда не станет ложным — цикл не завершится. Частая причина —
забыли изменить переменную условия:

```python
count = 1
while count <= 5:
    print(count)      # count всегда 1 → печатает бесконечно
```

Осознанный бесконечный цикл пишут как `while True:`.

---

## Вывод

- `if` и `while` — составные инструкции: `ключевое слово` + `условие` + `:` +
  блок с отступом.
- **Условие** — выражение; интерпретатор вычисляет его в объект и проверяет на
  истинность. Ложны: `False`, `None`, `0`, `""`, пустые контейнеры; все
  остальное истинно.
- `if` / `elif` / `else` — выбор **одной** ветки: срабатывает первое истинное
  условие.
- `while` — повтор тела, **пока** условие истинно; нужно менять переменную
  условия, иначе цикл бесконечен.
