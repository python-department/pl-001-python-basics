# Практическое задание: основы работы с Git и GitHub

Цель задания — на практике пройти базовый цикл работы с Git и GitHub: форк, клонирование, синхронизация изменений через Pull Request, коммиты и откат ошибочных изменений.

## Шаг 1. Форк и клонирование репозитория

1. Перейдите в [репозиторий](https://github.com/python-department/pl-001-toy-repo) с практическим заданием.
2. Сделайте форк репозитория в свой аккаунт на GitHub (кнопка **Fork**).
3. Склонируйте себе **свой форк** (не оригинальный репозиторий).

## Шаг 2. Синхронизация изменений через Pull Request

После того как вы склонировали репозиторий, преподаватель добавит в оригинальный репозиторий новый файл для редактирования.

1. Откройте Pull Request из оригинального репозитория (`upstream`) в свой форк — так вы «затащите» обновления преподавателя к себе на GitHub.
2. Смержите этот Pull Request в свой форк.
3. Скачайте обновления в локальный репозиторий.

## Шаг 3. Первое изменение файла

1. Откройте добавленный файл и внесите в него любой текст (например, короткое приветствие или пару предложений о себе).
2. Сохраните файл, зафиксируйте изменения и отправьте их на GitHub.

## Шаг 4. Второе изменение файла

1. Снова откройте тот же файл и внесите в него дополнительные изменения.
2. Закоммитьте изменения (пока **не отправляйте** их на GitHub).

## Шаг 5. Откат ошибочного коммита

Представим, что последний коммит оказался неудачным — например, в файл случайно попал пароль, токен или другой секрет, который нельзя отправлять в общий репозиторий.

1. Откатите последний коммит, оставив изменения в рабочей копии для правки.
2. Откройте файл и исправьте его содержимое — уберите «утекшие» данные и оставьте только корректный текст.
3. Заново проиндексируйте и закоммитьте исправленные изменения.

## Что должно получиться в итоге

- Ваш форк репозитория содержит файл преподавателя со всеми внесенными вами правками.
- История коммитов не содержит «опасного» коммита с секретом — он был заменен исправленным.
- Все финальные изменения отправлены на GitHub и видны в вашем форке.
