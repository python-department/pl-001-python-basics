# Фабрики функций

> **Главная мысль.** **Фабрика функций (function factory)** — это функция,
> которая принимает параметры настройки и возвращает новую функцию,
> сконфигурированную этими параметрами. Настройки сохраняются в замыкании,
> поэтому возвращенную функцию не нужно каждый раз вызывать со всеми
> параметрами. Одна фабрика порождает произвольное число функций с общей
> логикой и разными значениями настроек.

---

## 1. Шаблон фабрики

Фабрика функций состоит из трех частей:

```python
from typing import Callable


def make_function(setting: int) -> Callable[[int], int]:  # 1. параметры настройки
    def function(argument: int) -> int:                   # 2. вложенная функция
        return argument + setting                         #    использует setting

    return function                                       # 3. возврат без вызова
```

1. Внешняя функция принимает параметры, определяющие поведение будущей
   функции.
2. Внутри определяется вложенная функция, которая использует эти параметры как
   свободные переменные (замыкание).
3. Внешняя функция возвращает вложенную функцию, **не вызывая** ее.

Принятое соглашение об именах: фабрики называют с префиксом `make_` или
`create_`, а возвращаемый тип аннотируют через `Callable`.

## 2. Примеры фабрик

### Фабрика без состояния

Вместо отдельных функций `square`, `cube` и т. д. достаточно одной фабрики.
Замыкание хранит только параметр настройки `exponent`, который не изменяется:

```python
from typing import Callable


def make_power(exponent: int) -> Callable[[float], float]:
    def power(number: float) -> float:
        return number ** exponent

    return power


square = make_power(2)
cube = make_power(3)

print(square(5))  # 25
print(cube(5))    # 125
```

### Фабрика с состоянием

Сочетание фабрики и `nonlocal` дает функции с индивидуальным состоянием.
Например, накопитель суммы:

```python
from typing import Callable


def make_accumulator(start_value: float = 0) -> Callable[[float], float]:
    total = start_value

    def add(amount: float) -> float:
        nonlocal total
        total += amount
        return total

    return add


budget = make_accumulator(1000)
score = make_accumulator()

print(budget(-200))  # 800
print(budget(-50))   # 750
print(score(10))     # 10
print(score(5))      # 15
```

---

## 3. Что дает фабрика функций

- **Повторное использование логики.** Общий код записан один раз, различия
  вынесены в параметры фабрики.
- **Раздельная настройка и вызов.** Параметры задаются при создании функции,
  а при вызове передаются только данные. Это удобно, когда функцию нужно
  передать туда, где вызов происходит с фиксированной сигнатурой (например, как
  `key` для `sorted`, который ожидает функцию одного аргумента).
- **Инкапсуляция состояния.** Настройки и накопленное состояние скрыты в
  замыкании и недоступны напрямую.
- **Независимость экземпляров.** Каждый вызов фабрики создает новую функцию со
  своими свободными переменными.

---

## Вывод

- **Фабрика функций** — функция, которая принимает параметры и возвращает
  вложенную функцию, использующую эти параметры через замыкание.
- Типичный вид: внешняя функция с параметрами настройки, вложенная функция с
  рабочей логикой и `return` вложенной функции без скобок.
- Каждый вызов фабрики создает независимую функцию. С помощью `nonlocal`
  фабрика может порождать функции с собственным изменяемым состоянием.
- Фабрики сокращают дублирование, позволяют разделить момент настройки и момент
  вызова и удобны там, где требуется передать функцию с заданной сигнатурой.
