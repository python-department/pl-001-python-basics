# Атрибуты экземпляров и атрибуты объекта класса

> **Главная мысль.** У объекта класса и у каждого его экземпляра есть
> **собственные пространства имен**. При обращении `instance.name` Python
> ищет атрибут сначала в пространстве имен экземпляра, а затем в пространстве
> имен его класса. Поэтому из экземпляра **видны** атрибуты класса, а из
> объекта класса атрибуты экземпляров **не видны**. Изменение атрибута класса
> сразу видно всем экземплярам, а присваивание через экземпляр создает
> атрибут только в этом экземпляре и класс не затрагивает.

---

## 1. Два вида пространств имен

В следующем примере определен класс с атрибутом класса `company` и
атрибутом экземпляра `name`, который создается в `__init__`:

```python
class Employee:
    company = "Acme"

    def __init__(self, name: str) -> None:
        self.name = name


alice = Employee("Alice")
bob = Employee("Bob")
```

Здесь три пространства имен: одно у объекта класса и по одному у каждого
экземпляра. Посмотрим, что в них хранится:

```python
print("company" in Employee.__dict__)  # True  -- атрибут класса
print("name" in Employee.__dict__)     # False -- атрибута экземпляра в классе нет
print(alice.__dict__)                  # {'name': 'Alice'}
print(bob.__dict__)                    # {'name': 'Bob'}
```

В пространстве имен экземпляров находятся только атрибуты, созданные
присваиванием через `self` (или через имя экземпляра). Атрибут `company`
находится только в пространстве имен объекта класса, в пространствах имен
экземпляров его нет. Методы, определенные в теле класса, тоже находятся в
пространстве имен класса, поэтому они также доступны всем экземплярам.

---

## 2. Поиск атрибута у экземпляра

Выражение `instance.name` вычисляется по правилу:

1. атрибут ищется в пространстве имен **экземпляра**; если найден — возвращается;
2. иначе атрибут ищется в пространстве имен **класса**; если найден —
   возвращается;
3. если нет и там, возникает `AttributeError`.

Поэтому атрибут класса доступен через экземпляр, хотя в самом экземпляре его
нет:

```python
print(alice.name)     # Alice -- найден в пространстве имен экземпляра
print(alice.company)  # Acme -- в экземпляре нет, найден в классе
print(bob.company)    # Acme -- тот же атрибут класса
print(alice.position)
# AttributeError: 'Employee' object has no attribute 'position'
```

По этому же правилу находятся методы: если в классе определен метод
`describe`, то при вызове `alice.describe()` он не обнаруживается в
`alice.__dict__` и берется из класса.

---

## 3. Атрибуты экземпляров независимы друг от друга

У каждого экземпляра свое пространство имен, поэтому одноименные атрибуты
разных экземпляров — разные ссылки, никак не связанные между собой. Изменение
атрибута одного экземпляра не влияет на остальные:

```python
alice.name = "Alice Smith"
print(alice.name)  # Alice Smith
print(bob.name)    # Bob
```

---

## 4. Из объекта класса атрибуты экземпляров недоступны

Объект класса не хранит ссылок на свои экземпляры. Поиск атрибута у объекта класса
выполняется только в его собственном пространстве имен, поэтому атрибуты
экземпляров через класс получить нельзя:

```python
print(Employee.company)  # Acme
print(Employee.name)
# AttributeError: type object 'Employee' has no attribute 'name'
```

Атрибут `name` создается отдельно для каждого экземпляра при выполнении
`__init__` и хранится в этом экземпляре. Класс описывает, как создавать
экземпляры, но не хранит их данные.

---

## 5. Изменение класса видно экземплярам

Экземпляры не копируют атрибуты класса, а находят их в классе при каждом
обращении. Поэтому изменение атрибута класса сразу отражается на всех
экземплярах, включая созданные ранее:

```python
Employee.company = "Globex"
print(alice.company)  # Globex
print(bob.company)    # Globex
```

То же верно для новых атрибутов класса, добавленных после создания
экземпляров:

```python
Employee.country = "USA"
print(alice.country)  # USA
print(bob.country)    # USA
```

---

## 6. Изменение экземпляра не видно классу

В обратную сторону это не работает. Присваивание атрибута через экземпляр
создает или изменяет атрибут **только в пространстве имен этого экземпляра**.
Класс и другие экземпляры его не видят:

```python
alice.position = "manager"
print(alice.position)  # manager
print(bob.position)
# AttributeError: 'Employee' object has no attribute 'position'
print(Employee.position)
# AttributeError: type object 'Employee' has no attribute 'position'
```

### Присваивание через экземпляр не меняет атрибут класса

Это правило справедливо и для имен, которые уже есть в классе. Присваивание
`alice.company = ...` не изменяет атрибут `company` класса: оно создает в
экземпляре `alice` собственный атрибут с таким же именем, который
**перекрывает (shadows)** атрибут класса при поиске:

```python
Employee.company = "Acme"
alice.company = "Initech"
print(alice.company)     # Initech -- найден в экземпляре, перекрывает атрибут класса
print(bob.company)       # Acme    -- у bob своего атрибута нет, берется из класса
print(Employee.company)  # Acme    -- класс не изменился
print(alice.__dict__)    # {'name': 'Alice Smith', 'position': 'manager', 'company': 'Initech'}
```

После удаления атрибута экземпляра перекрытие исчезает, и снова виден
атрибут класса:

```python
del alice.company
print(alice.company)  # Acme
```

Чтобы изменить атрибут именно **класса**, присваивание нужно выполнять через
объект класса: `Employee.company = ...`. Внутри метода экземпляра объект класса
можно получить как `type(self)`.

### Составное присваивание

Запись `instance.counter += 1` состоит из двух шагов: чтение `instance.counter`
(по правилу поиска значение будет взято из класса) и присваивание результата
атрибуту **экземпляра**. Поэтому атрибут класса остается прежним:

```python
class Visits:
    total = 0


first_visit = Visits()
first_visit.total += 1
print(first_visit.total)  # 1 -- создан атрибут экземпляра
print(Visits.total)       # 0 -- атрибут класса не изменился
```

## 7. Изменяемые атрибуты класса

Правило, по которому присваивание через экземпляр создает атрибут
экземпляра, не действует, когда атрибут не присваивается, а **изменяется на месте**. Если
атрибут класса ссылается на изменяемый объект, то все экземпляры работают с
**одним и тем же объектом**:

```python
class Team:
    members = []  # один список на весь класс


first_team = Team()
second_team = Team()
first_team.members.append("Alice")
print(second_team.members)                 # ['Alice'] -- список общий для всех экземпляров
print(Team.members is first_team.members)  # True
```

Метод `append` изменяет объект, на который указывает атрибут, а присваивания
атрибуту не происходит. Поэтому никакого нового атрибута экземпляра не
создается, и изменение видно всем.

Если каждому экземпляру нужен собственный список, его создают в `__init__`
для каждого экземпляра отдельно:

```python
class Team:
    def __init__(self) -> None:
        self.members = []  # отдельный список у каждого экземпляра


first_team = Team()
second_team = Team()
first_team.members.append("Alice")
print(first_team.members)   # ['Alice']
print(second_team.members)  # []
```

---

## 8. Что где хранить

Правило выбора вытекает из различий, рассмотренных выше:

- **атрибуты экземпляра** — данные, которые различаются у разных объектов:
  имя сотрудника, баланс счета, список участников команды. Они создаются в
  `__init__`;
- **атрибуты класса** — значения, общие для всех экземпляров: константы,
  настройки по умолчанию, счетчики и реестры, относящиеся ко всему классу.

Типичный пример общего состояния — счетчик созданных экземпляров. Он
хранится в атрибуте класса и изменяется присваиванием через объект класса, а
не через `self`:

```python
class Employee:
    employees_count = 0

    def __init__(self, name: str) -> None:
        self.name = name
        Employee.employees_count += 1


alice = Employee("Alice")
bob = Employee("Bob")
print(Employee.employees_count)  # 2
print(alice.employees_count)     # 2 -- атрибут класса виден через экземпляр
```

Итоговое сравнение:

| | Атрибут экземпляра | Атрибут класса |
|---|---|---|
| Где хранится | в пространстве имен экземпляра | в пространстве имен объекта класса |
| Сколько копий | по одному на каждый экземпляр | один на весь класс |
| Как создается | `self.name = value` | присваивание в теле класса или `Class.name = value` |
| Доступ через экземпляр | да | да (если экземпляр не перекрывает его своим атрибутом) |
| Доступ через объект класса | нет | да |
| Изменение через экземпляр | меняет только этот экземпляр | не меняет класс: создает атрибут экземпляра |
| Изменение видно другим экземплярам | нет | да, если менять через объект класса |

---

## Вывод

- У объекта класса и у каждого экземпляра **свое пространство имен**.
  Атрибуты экземпляров хранятся в `instance.__dict__`, атрибуты класса — в
  `Class.__dict__`.
- Атрибут у экземпляра ищется сначала в самом экземпляре, затем в его классе.
  Поэтому атрибуты класса доступны через экземпляр, а методы находятся в
  классе.
- Атрибуты разных экземпляров независимы: изменение состояния одного
  экземпляра не затрагивает другие экземпляры.
- Через объект класса атрибуты экземпляров недоступны: класс не хранит
  данные своих экземпляров.
- Добавление или изменение атрибута класса (через объект класса) сразу видно
  всем существующим экземплярам.
- Присваивание через экземпляр всегда создает или изменяет **атрибут
  экземпляра**: класс и другие экземпляры его не видят. Если такое имя есть в
  классе, атрибут экземпляра перекрывает его.
- Изменяемый объект, на который ссылается атрибут класса, при изменении на
  месте (`append`) остается общим для всех экземпляров. Данные, различающиеся
  у объектов, создаются в `__init__`.
