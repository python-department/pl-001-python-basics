# Объекты в Python: состояние и поведение

> **Главная мысль.** Любые данные в Python представлены **объектами**.
> **Объект** — это абстракция над данными в памяти компьютера, которая
> определяет, какие значения эти данные могут принимать и какие операции над
> ними допустимы. Иначе говоря, объект объединяет **состояние** (данные) и
> **поведение** (допустимые операции). Числа, строки, списки, функции — это
> встроенные объекты. Для решения прикладных задач их набора может быть
> недостаточно, поэтому Python позволяет определять **собственные типы
> объектов**.

---

## 1. Все данные — объекты

В [конспекте про идентичность, тип и значение](../../lesson02/conspects/05-objects-identity-type-value.md)
мы выяснили, что любые данные в программе на Python представлены объектами, а
у каждого объекта есть идентичность, тип данных и значение. Тип данных при
этом определяет, какие значения может хранить объект и какие операции над ним
допустимы.

Это верно не только для чисел и строк. Объектами являются также функции,
встроенные и пользовательские:

```python
def square(number: int) -> int:
    return number * number


print(type(42))      # <class 'int'>
print(type("text"))  # <class 'str'>
print(type([1, 2]))  # <class 'list'>
print(type(square))  # <class 'function'>
print(type(len))     # <class 'builtin_function_or_method'>
```

Для любого из этих объектов можно получить идентичность (`id()`), тип
(`type()`) и обратиться к его атрибутам и методам.

## 2. Состояние и поведение

С точки зрения использования объект характеризуют две стороны:

- **состояние (state)** — данные, которые хранит объект;
- **поведение (behavior)** — операции, которые допустимы над этим объектом.

Рассмотрим эти стороны на примере встроенных объектов:

| Объект | Состояние | Поведение |
|---|---|---|
| `42` (`int`) | целое число `42` | сложение, умножение, сравнение |
| `"Alice"` (`str`) | последовательность символов | индексация, срезы, `upper()`, `split()` |
| `[1, 2, 3]` (`list`) | упорядоченный набор элементов | индексация, `append()`, `sort()`, `pop()` |
| `{"a": 1}` (`dict`) | набор пар (ключ, значение) | чтение по ключу, `keys()`, `items()`, `update()` |
| функция | локальные и свободные переменные, ячейки замыканий, значения по умолчанию, аннотации | вызов |

Состояние объекта может меняться, если тип изменяемый, а поведение задается
типом и одинаково для всех объектов этого типа:

```python
first_list = [3, 1, 2]
second_list = [10, 20]
first_list.append(4)
second_list.append(30)
print(first_list)   # [3, 1, 2, 4]
print(second_list)  # [10, 20, 30]
```

Операция `append()` определена один раз для типа `list` и доступна каждому
списку. Результат ее выполнения зависит от состояния конкретного списка:
у `first_list` и `second_list` оно разное.

Поэтому тип данных можно описать как **набор операций (поведения) над
состоянием определенной структуры**. Объекты одного типа имеют общее
поведение и разные состояния.

## 3. Когда встроенных объектов недостаточно

Встроенных типов достаточно для хранения чисел и строк, а также списков и
словарей, составленных из них. Но
программы создают модели более сложных сущностей: студента, банковского счета,
товара на складе. Попробуем построить модель студента только из встроенных
объектов.

Состояние можно хранить в словаре, а поведение оформить отдельными
функциями:

```python
student = {"name": "Alice", "grades": [5, 4]}


def add_grade(student_data: dict, grade: int) -> None:
    student_data["grades"].append(grade)


def calculate_average(student_data: dict) -> float:
    return sum(student_data["grades"]) / len(student_data["grades"])


add_grade(student, 5)
print(calculate_average(student))  # 4.666666666666667
```

Код работает, но у такого подхода есть недостатки:

1. **Состояние и поведение не связаны.** Функции `add_grade` и
   `calculate_average` находятся в пространстве имен модуля и никак не
   привязаны к данным студента. По коду невозможно определить, к каким
   объектам они применимы.
2. **Нет отдельного типа.** `type(student)` возвращает `dict`, как и для
   любого другого словаря. Нельзя отличить словарь студента от словаря
   товара, а функцию `add_grade` можно вызвать с любым словарем.
3. **Структура ничем не гарантируется.** Ключи словаря — произвольные
   строки. Опечатка в имени ключа (`"grade"` вместо `"grades"`) обнаружится
   только при выполнении программы.
4. **Состояние доступно любому коду.** Любая функция или объект, получившие
   ссылку на словарь, могут изменить его напрямую, например
   `student["grades"].append(10)` или `student["grades"] = []`, минуя
   `add_grade`. Состояние может меняться не только через допустимое
   поведение.

Для таких задач нужен собственный тип данных, который:

- задает структуру состояния (какие данные и в каком виде хранит каждый объект типа);
- хранит поведение рядом с состоянием (какие операции допустимы);
- определяет, какие операции предназначены для изменения состояния, и
  ограничивает прямой доступ к нему из остального кода;
- позволяет создавать любое число объектов этого типа, у каждого из
  которых свое состояние.

## 4. Пользовательские типы объектов

Python позволяет определять собственные типы объектов. Для этого
используется конструкция **`class`**: она создает **объект класса**
(class object), который описывает новый тип. Объект класса, в свою очередь,
используется для создания **экземпляров (instances)** — объектов этого типа.

Заметим, что мы уже работали с объектами классов. Имена `int`, `str`,
`list`, `dict` — это объекты классов встроенных типов, а числа, строки и
списки — их экземпляры:

```python
print(type(42))           # <class 'int'>
print(type(int))          # <class 'type'>
print(int("15"))          # 15 -- вызов объекта класса int создает экземпляр
print(str.upper("text"))  # TEXT -- метод, определенный в объекте класса str
```

Из этого примера следует:

- `int` — это объект, и он тоже имеет тип (`type`);
- вызов объекта класса (`int("15")`) создает экземпляр класса;
- методы типа (`upper`) хранятся в объекте класса (`str`) и доступны через
  него.

В следующих конспектах более подробно рассматривается определение
собственных классов.

## Вывод

- Любые данные в Python представлены **объектами**; объектами являются также
  функции и, как будет показано далее, классы.
- **Объект** объединяет **состояние** (данные) и **поведение** (допустимые
  операции). Поведение определяется типом и одинаково для всех объектов
  одного типа, а состояние у каждого объекта свое.
- Встроенные типы `int`, `str`, `list` — объекты классов, а
  числа, строки и списки — их экземпляры.
