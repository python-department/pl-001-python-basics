# Атрибуты объекта класса

> **Главная мысль.** **Атрибут (attribute)** — это имя, связанное с объектом и
> доступное через точку: `объект.имя`. Атрибуты объекта класса (**атрибуты
> класса**) создаются присваиваниями в теле класса, а также могут быть
> добавлены, изменены и удалены уже после его создания. Хранятся они в
> пространстве имен класса и могут ссылаться на объекты любого типа. Объект
> класса существует в единственном числе, поэтому его атрибуты образуют общее
> состояние, одно на весь класс.

---

## 1. Что такое атрибут

Атрибутом называется имя, которое хранится в пространстве имен объекта и
доступно через точку. С атрибутами мы уже работали: `Product.__name__` в
предыдущем конспекте, `square.__doc__` у функции и методы встроенных типов
(`text.upper`) — это тоже атрибуты.

Атрибуты, которые создаются присваиваниями в теле класса, называются
**атрибутами класса (class attributes)**. Значением атрибута может быть
объект любого типа:

```python
class Product:
    category = "general"    # строка
    tax_rate = 0.2          # число
    tags = ["new", "sale"]  # список
    description = None      # None
```

Каждое присваивание в теле класса связывает имя в пространстве имен класса с
объектом (см. [предыдущий конспект](02-class-object.md)).

## 2. Доступ к атрибутам класса

### Чтение атрибута

Для чтения атрибута указывается имя класса, точка и имя атрибута:

```python
class Product:
    category = "general"
    tax_rate = 0.2
    tags = ["new", "sale"]


print(Product.category)  # general
print(Product.tax_rate)  # 0.2
print(Product.tags[0])   # new -- атрибут ссылается на список, поэтому его можно индексировать
```

Выражение `Product.category` вычисляется в два шага: сначала по имени
`Product` находится объект класса, затем в его пространстве имен ищется
атрибут `category`. Полученное значение — обычный объект, с которым
допустимы все операции его типа (индексация, вызов методов, арифметика).

Если атрибута с таким именем нет, возникает `AttributeError`:

```python
print(Product.price)
# AttributeError: type object 'Product' has no attribute 'price'
```

### Изменение значения атрибута

Присваивание через точку связывает имя атрибута с новым объектом:

```python
Product.tax_rate = 0.25
print(Product.tax_rate)  # 0.25
```

Это **перепривязка** имени в пространстве имен класса: имя `tax_rate` теперь
ссылается на другой объект. Объект класса при этом остается тем же.

### Добавление нового атрибута

Объекты классов изменяемы: атрибут можно добавить в любой момент, в том числе
вне тела класса. Достаточно присвоить значение несуществующему атрибуту:

```python
Product.currency = "USD"
print(Product.currency)  # USD
```

### Удаление атрибута

Атрибут удаляется инструкцией `del`, как и обычная переменная:

```python
del Product.currency
print(Product.currency)
# AttributeError: type object 'Product' has no attribute 'currency'
```

Добавление, замена и удаление атрибутов объекта во время выполнения программы,
уже после его создания, называется **monkey patching**. На практике этот прием
без крайней необходимости применять не следует:

- определение класса перестает соответствовать его фактическому состоянию:
  по телу класса нельзя узнать, какие атрибуты у него есть на самом деле;
- изменение действует на все места программы, использующие класс, поэтому
  источник неожиданного поведения трудно найти;
- удаление или замена атрибута может нарушить код, который на него
  рассчитывает.

Оправданные случаи применения редки: например, временная подмена атрибута в
тестах или исправление ошибки в стороннем коде, который нельзя изменить
напрямую.

Итого над атрибутами класса выполняются те же операции, что над элементами
словаря: чтение, запись, добавление и удаление по имени. Это не случайно:
пространство имен класса хранится именно в виде словаря.

## 3. Атрибуты и пространство имен класса

Пространство имен класса доступно через специальный атрибут `__dict__`
(или, что то же самое, через встроенную функцию `vars()`). Каждый атрибут
класса — это запись в нем: ключ — имя атрибута, значение — объект.

```python
class Product:
    category = "general"
    tax_rate = 0.2


print("category" in Product.__dict__)  # True
print(Product.__dict__["tax_rate"])    # 0.2
```

Выведем содержимое пространства имен, исключив служебные имена, которые
интерпретатор добавляет сам (их имена начинаются и заканчиваются двумя
подчеркиваниями):

```python
user_attributes = {
    name: value
    for name, value in vars(Product).items()
    if not name.startswith("__")
}
print(user_attributes)  # {'category': 'general', 'tax_rate': 0.2}
```

Обратите внимание: `Product.__dict__` — это не обычный словарь, а
**представление только для чтения (`mappingproxy`)**. Читать из него можно, а
записывать нельзя; изменения вносятся только через присваивание атрибутов:

```python
Product.__dict__["category"] = "food"
# TypeError: 'mappingproxy' object does not support item assignment
Product.category = "food"  # правильный способ
```

## 4. Динамический доступ по имени

В записи `Product.category` имя атрибута указано в тексте программы. Иногда
имя становится известно только во время выполнения: например, его вводит
пользователь или оно читается из файла. Тогда имя находится в переменной типа
`str`, а запись через точку не подходит: она всегда ищет атрибут с тем именем,
которое написано после точки, а не с тем, которое хранится в переменной:

```python
class Product:
    category = "general"


attribute_name = "category"  # имя атрибута получено в виде строки
print(Product.attribute_name)
# AttributeError: type object 'Product' has no attribute 'attribute_name'
```

Для работы с атрибутом по имени, заданному строкой, используются встроенные
функции:

| Функция | Действие | Эквивалент |
|---|---|---|
| `getattr(object, name)` | прочитать атрибут | `object.name` |
| `getattr(object, name, default)` | прочитать атрибут или вернуть `default`, если атрибута нет | |
| `hasattr(object, name)` | проверить наличие атрибута | |
| `setattr(object, name, value)` | записать атрибут | `object.name = value` |
| `delattr(object, name)` | удалить атрибут | `del object.name` |

```python
print(getattr(Product, attribute_name))  # general
print(getattr(Product, "price", 0))      # 0 -- атрибута нет, возвращено значение по умолчанию
print(hasattr(Product, "category"))      # True
setattr(Product, "price", 100)
print(Product.price)  # 100
```

## 5. Атрибуты класса как общее состояние

Объект класса существует в единственном экземпляре, поэтому его атрибуты —
**общее состояние**, одно для всех, кто к нему обращается. Любое изменение
видно везде, где используется этот класс. Рассмотрим это на примере счетчика,
доступного из разных функций:

```python
class Counter:
    value = 0


def increment() -> None:
    Counter.value += 1


def show() -> None:
    print(f"Counter value: {Counter.value}")


increment()
increment()
show()  # Counter value: 2
```

Запись `Counter.value += 1` выполняет чтение атрибута, сложение и запись
результата обратно в атрибут того же объекта класса. Обе функции работают с
одним и тем же `Counter.value`.

Если значением атрибута является изменяемый объект, его можно менять и без
присваивания атрибута. В следующем примере список изменяется на месте, а
атрибут продолжает ссылаться на тот же объект:

```python
class Registry:
    names = []


Registry.names.append("first")
Registry.names.append("second")
print(Registry.names)  # ['first', 'second']
```

---

## Вывод

- **Атрибут** — имя, связанное с объектом и доступное через точку. Атрибуты
  класса создаются присваиваниями в теле класса и могут быть ссылками на
  объекты любых типов.
- Чтение: `Class.name`. Отсутствующий атрибут вызывает `AttributeError`.
  Запись и добавление: `Class.name = value`. Удаление: `del Class.name`.
- Атрибуты класса хранятся в его пространстве имен, доступном как
  `Class.__dict__` (или `vars(Class)`). Это представление только для чтения
  (`mappingproxy`), изменять атрибуты нужно через присваивание.
- Для работы с атрибутом по имени, заданному строкой, используются `getattr`,
  `hasattr`, `setattr` и `delattr`.
- Атрибуты класса — общее состояние: объект класса один, поэтому изменение
  атрибута видно во всех местах программы, где используется класс.
