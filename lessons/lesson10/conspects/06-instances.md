# Экземпляры класса

> **Главная мысль.** Атрибуты объекта класса образуют единственное состояние,
> общее для всей программы. Когда нужно несколько объектов с одинаковым
> поведением, но с разным состоянием, используются **экземпляры класса
> (instances)**. Экземпляр создается **вызовом объекта класса**:
> `ClassName()`. Каждый вызов создает новый объект, тип которого — этот
> класс. У каждого экземпляра есть собственное пространство имен для
> хранения его состояния.

---

## 1. Мотивация: несколько объектов одного вида

Предположим, нужно представить банковские счета: у каждого есть владелец и
баланс. Если хранить данные в атрибутах объекта класса, получится только
один счет, поскольку объект класса существует в единственном числе:

```python
class BankAccount:
    owner = "Alice"
    balance = 100


print(BankAccount.owner)    # Alice
print(BankAccount.balance)  # 100
```

Для второго счета с другим владельцем и балансом пришлось бы определять второй
класс, дублируя код. Для десяти тысяч клиентов банка такой подход
неприменим.

Решение: использовать **один класс**, который описывает, что такое банковский
счет вообще, и создавать на его основе **сколько угодно экземпляров**. Все
экземпляры имеют общее поведение, определяемое классом, но каждый хранит
собственное состояние. Это аналогично встроенным типам: тип `list` один,
а списков в программе может быть сколько угодно, и в каждом из них свои
элементы.

## 2. Создание экземпляров

Объект класса является **вызываемым (callable)**, как и функция. Результатом
вызова является новый **экземпляр класса**:

```python
class BankAccount:
    pass


first_account = BankAccount()
second_account = BankAccount()
print(first_account)   # <__main__.BankAccount object at 0x000001B2C3D4E5F0>
print(second_account)  # <__main__.BankAccount object at 0x000001B2C3D4E650>
```

Каждый вызов `BankAccount()` создает **новый** объект: это видно по разным
адресам в выводе (в CPython это значение `id()`). Имена `first_account` и
`second_account` привязываются к разным объектам.

```python
print(first_account is second_account)         # False
print(type(first_account))                     # <class '__main__.BankAccount'>
print(isinstance(first_account, BankAccount))  # True
```

- тип экземпляра — класс, с помощью которого он создан;
- `isinstance(object, Class)` — принятый способ проверить, является ли объект
  экземпляром указанного класса;
- класс — единственный, а экземпляров у него может быть любое количество.

Вызов объекта класса — это такой же вызов, как и вызов функции: он может
находиться в любом выражении, его результат можно сохранить в переменную,
поместить в список или передать в функцию.

```python
accounts = [BankAccount(), BankAccount(), BankAccount()]
print(len(accounts))               # 3
print(accounts[0] is accounts[1])  # False
```

## 3. Собственное состояние экземпляра

Экземпляр — полноценный объект со своим **пространством имен**, в котором
хранятся его атрибуты. Такие атрибуты называются **атрибутами экземпляра
(instance attributes)**. Как и у объекта класса, их можно создавать
присваиванием через точку:

```python
first_account = BankAccount()
second_account = BankAccount()
first_account.owner = "Alice"
first_account.balance = 100
second_account.owner = "Bob"
second_account.balance = 250
print(first_account.owner, first_account.balance)    # Alice 100
print(second_account.owner, second_account.balance)  # Bob 250
```

У каждого экземпляра значения атрибутов свои. Если изменить атрибут одного
экземпляра, атрибуты других экземпляров останутся прежними. Пространство имен
экземпляра доступно через атрибут `__dict__`, который является обычным
словарем:

```python
print(first_account.__dict__)   # {'owner': 'Alice', 'balance': 100}
print(second_account.__dict__)  # {'owner': 'Bob', 'balance': 250}
first_account.balance += 50
print(first_account.balance)   # 150
print(second_account.balance)  # 250
```

Если обратиться к атрибуту, которого нет у экземпляра, возникает
`AttributeError`:

```python
third_account = BankAccount()
print(third_account.balance)
# AttributeError: 'BankAccount' object has no attribute 'balance'
```

Итак, класс задает тип, а **состояние хранится в экземплярах**. Один и тот же
класс используется для множества объектов, у каждого из которых набор
значений свой. Общее для всех экземпляров поведение задается методами, которые
рассматриваются в следующем конспекте.

---

## 4. Недостаток ручного создания атрибутов

Присваивание атрибутов вручную после создания экземпляра работает, но
неудобно и ненадежно:

```python
account = BankAccount()
account.owner = "Alice"
account.balanse = 100  # опечатка: создан новый атрибут balanse
print(account.balance)
# AttributeError: 'BankAccount' object has no attribute 'balance'
```

Каждый раз приходится повторять один и тот же набор присваиваний, а о нем
легко забыть или допустить в нем опечатку. Желательно, чтобы начальное состояние
экземпляра задавалось автоматически в момент его создания. Для этого в классе
определяется специальный метод инициализации, который разбирается в
следующем конспекте.

---

## Вывод

- Атрибуты объекта класса — единственное состояние на весь класс. Чтобы
  создать несколько объектов с одинаковым поведением и разным состоянием,
  используют **экземпляры**.
- Экземпляр создается вызовом объекта класса: `ClassName()`. Каждый вызов
  возвращает новый объект, тип которого — этот класс.
- Тип экземпляра можно получить через `type(instance)`, а принадлежность
  классу проверить функцией `isinstance(instance, Class)`.
- У каждого экземпляра есть собственное пространство имен (`__dict__`) с
  **атрибутами экземпляра**. Атрибуты разных экземпляров независимы друг от
  друга.
- Создавать атрибуты экземпляров присваиваниями вручную неудобно и
  подвержено ошибкам; начальное состояние задается при создании экземпляра
  специальным методом.
