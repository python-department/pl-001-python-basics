# Объект класса: инструкция class

> **Главная мысль.** Инструкция **`class`** создает **объект класса (class
> object)** — обычный объект Python, который описывает новый тип данных.
> В отличие от Java или C++, где классы обрабатываются на этапе компиляции,
> объекты классов в Python создаются во время исполнения программы.
> Интерпретатор последовательно выполняет инструкции **тела класса** в
> отдельном пространстве имен, затем создает по его содержимому объект класса,
> который связывается с именем, указанным в заголовке инструкции `class`. Имена,
> определенные в теле класса, становятся атрибутами этого объекта. Они не
> попадают в пространство имен модуля и не доступны как обычные переменные ни
> остальному коду, ни функциям, определенным в теле класса: обратиться к ним
> можно только как к атрибутам, через имя класса.

---

## 1. Синтаксис определения класса

Объект класса создается инструкцией `class`. Он описывает тип данных: структуру
состояния и поведение, общее для всех объектов этого типа (см.
[предыдущий конспект](01-objects-in-python.md)). Сами объекты этого типа —
**экземпляры (instances)** — создаются позже, на основе объекта класса; в этом
конспекте они не рассматриваются. Для краткости объект класса далее называется
также просто **классом**.

После ключевого слова `class` указывается **идентификатор** (имя) класса,
затем двоеточие и тело класса — блок кода с отступом:

```python
class Product:
    pass
```

Правила записи те же, что у `def`:

- заголовок `class Имя:` заканчивается двоеточием;
- тело записывается с отступом (по PEP 8 — четыре пробела);
- тело не может быть пустым. Если содержимого пока нет, используется
  инструкция `pass` или выражение `...` (литерал объекта `Ellipsis`),
  вычисление которого не имеет побочных эффектов.

По соглашению PEP 8 имена классов записываются в стиле **PascalCase**: каждое слово начинается с заглавной буквы,
подчеркиваний нет (`Product`, `BankAccount`, `HttpClient`). Так класс визуально отличается от функций и
переменных, которые именуются в стиле `snake_case`.

Если первой инструкцией тела записана строка, она становится документирующей
строкой (docstring) класса, как и у функций:

```python
class Product:
    """Description of a product."""


print(Product.__doc__)  # Description of a product.
help(Product)
```

Запись `Product.__doc__` — это **обращение к атрибуту** объекта. Атрибут — имя,
связанное со значением и хранящееся внутри объекта. Чтобы прочитать значение
атрибута, после имени объекта через точку указывается имя атрибута:
`объект.атрибут`. Здесь атрибут `__doc__` объекта класса хранит docstring. Если
у объекта нет атрибута с указанным именем, возникает `AttributeError`.

Функция `help()` выводит справку по объекту, которая включает в себя его
docstring:

```
Help on class Product in module __main__:

class Product(builtins.object)
 |  Description of a product.
 |
 ...
```

В выводе опущены служебные разделы, которые Python добавляет автоматически.

## 2. Класс — это объект

Инструкция `class`, как и `def`, **создает объект** и **связывает** его с
именем в текущем пространстве имен. Для функции создается объект типа
`function`, для класса — **объект класса**.

```python
class Product:
    category = "general"


print(Product)           # <class '__main__.Product'>
print(type(Product))     # <class 'type'>
print(Product.__name__)  # Product
```

Из вывода видно:

- имя `Product` ссылается на объект, который сам по себе имеет тип `type`.
  Тип `type` — это тип всех объектов классов; именно поэтому в предыдущем
  конспекте `type(int)` вернул `<class 'type'>`;
- у объекта класса есть атрибут `__name__` с именем класса. Он хранит строку,
  заданную в заголовке инструкции `class`, и не зависит от того, какие
  переменные потом будут ссылаться на этот объект.

### Объект класса можно использовать как любой другой объект

Поскольку класс — объект, с ним допустимы те же операции, что и с другими
объектами: привязка к другим именам, помещение в коллекции, передача в функции
в качестве аргумента и возврат из функций.

```python
class Product:
    category = "general"


def describe(target_class: type) -> str:
    return target_class.__name__


classes = [Product]
OtherName = Product
print(OtherName is Product)  # True -- один и тот же объект
print(classes[0].category)   # general
print(describe(Product))     # Product
```

Присваивание `OtherName = Product` не создает новый класс, а привязывает к
существующему объекту второе имя, как и для любого другого объекта (см.
[конспект про переменные и ссылки](../../lesson02/conspects/05-objects-identity-type-value.md)).

### Время выполнения инструкции class

Объект класса создается не на этапе компиляции, а во время выполнения
программы, в момент, когда поток исполнения достигает инструкции `class`.
Поэтому каждое выполнение этой инструкции создает **новый** объект класса:

```python
def create_class() -> type:
    class Temporary:
        pass
    return Temporary


first_class = create_class()
second_class = create_class()
print(first_class is second_class)  # False -- два разных объекта класса
print(first_class.__name__)         # Temporary
print(second_class.__name__)        # Temporary
```

Классы создаются внутри функций редко, но пример показывает, что `class` — это
такая же исполняемая инструкция, как `def`.

## 3. Тело класса выполняется при определении

Тело класса — это обычный код, который исполняется **один раз**, сверху вниз,
в момент выполнения инструкции `class`. В нем допустимы любые инструкции:
присваивания, вызовы функций, условия, циклы.

```python
print("Before class")


class Report:
    print("Inside class body")
    title = "Monthly"
    print(f"Title is {title}")


print("After class")
```

Вывод:

```
Before class
Inside class body
Title is Monthly
After class
```

Строки из тела класса выводятся в момент выполнения инструкции `class`, между
выводом строк `Before class` и `After class`. Повторно тело не выполняется:
при дальнейшей работе с классом используется уже созданный объект.

Все имена, **связанные** в теле класса, становятся атрибутами объекта класса.
Это относится не только к явным присваиваниям, но и к любым другим способам
связывания имени, например к переменной цикла:

```python
class Table:
    for column in range(3):
        print(column)  # 0, 1, 2


print(Table.column)  # 2 -- переменная цикла осталась атрибутом класса
```

Обычно в теле класса записывают присваивания (атрибуты) и определения
функций (методы), а побочные действия, как в примере выше, не используют.

## 4. Область видимости тела класса

Для выполнения тела класса Python создает отдельное **пространство имен
класса (class namespace)**. Пока тело выполняется, присваивания связывают имена
именно в нем, а не в пространстве имен модуля. Когда выполнение тела
завершается, объект класса создается на основе этого пространства имен, и
каждое имя из него становится атрибутом объекта класса.

### Имена тела класса не попадают в пространство имен модуля

После выполнения `class` имена из его тела недоступны напрямую, а только как
атрибуты через имя класса и точку:

```python
class Product:
    base_price = 100


print(Product.base_price)  # 100
print(base_price)          # NameError: name 'base_price' is not defined
```

Отсюда следует, что имена тела класса и имена модуля не пересекаются, и
одноименные переменные не конфликтуют:

```python
discount = 10


class Product:
    discount = 25


print(discount)          # 10 -- переменная модуля
print(Product.discount)  # 25 -- атрибут класса
```

### Что видит код в теле класса

Код тела класса ищет имена сначала в пространстве имен самого класса, а затем
в пространстве имен модуля (и встроенных имен). Поэтому в теле можно
использовать как глобальные имена, так и атрибуты, определенные выше по тексту
тела:

```python
discount = 10


class Product:
    base_price = 100
    final_price = base_price - discount  # base_price -- из класса, discount -- из модуля


print(Product.final_price)  # 90
```

В отличие от тела функции, в теле класса можно прочитать глобальное имя и
присвоить его значение одноименному атрибуту:

```python
discount = 10


class Product:
    discount = discount + 5  # справа -- переменная модуля, слева -- атрибут класса


print(discount)          # 10
print(Product.discount)  # 15
```

В функции такая запись привела бы к `UnboundLocalError`, так как имя,
которому присваивается значение, считалось бы локальным во всем теле функции.

### Тело класса не является объемлющей областью для функций

Функция, определенная в теле класса, — это обычная функция, имя которой
становится атрибутом класса. Поиск имен внутри такой функции подчиняется
правилу LEGB (см. [конспект про поиск имен](../../lesson07/conspects/04-symbol-tables-and-name-lookup.md)),
и пространство имен класса в этом поиске **не участвует**: оно не является
объемлющей областью видимости (Enclosing) для вложенных функций.

```python
class Product:
    base_price = 100

    def show_price() -> None:
        print(base_price)  # NameError: name 'base_price' is not defined


Product.show_price()
```

Имя `base_price` определено в пространстве имен класса, а функция
`show_price` ищет его в своем локальном пространстве, затем в пространстве
модуля и во встроенных именах. Ни в одном из них имени нет. Чтобы обратиться к
атрибуту класса из функции, нужно указать его полностью — через имя класса:

```python
class Product:
    base_price = 100

    def show_price() -> None:
        print(Product.base_price)  # имя Product ищется в пространстве имен модуля


Product.show_price()  # 100
```

Имя `Product` к моменту вызова функции уже связано с объектом класса в
пространстве имен модуля, поэтому поиск этого имени завершается успешно. Для
обращения к атрибутам внутри методов в Python существуют и более удобные
способы, которые рассматриваются далее.

## Вывод

- Инструкция **`class`** создает **объект класса** и связывает его с именем,
  указанным в заголовке инструкции `class`. Имена классов по PEP 8
  записываются в стиле PascalCase.
- Объект класса — обычный объект типа `type`: его можно привязывать к другим
  именам, хранить в коллекциях, передавать в функции и возвращать из них.
  Каждое выполнение `class` создает новый объект класса.
- Тело класса исполняется один раз, при выполнении инструкции `class`, в
  отдельном **пространстве имен класса**. Все имена, связанные в теле,
  становятся атрибутами объекта класса.
- Имена тела класса не попадают в пространство имен модуля и не конфликтуют
  с одноименными глобальными именами. В теле класса доступны как его
  атрибуты, так и имена глобального пространства имен.
- Пространство имен класса **не является** объемлющей областью видимости для
  функций, определенных в теле: внутри функции к атрибуту класса можно
  обратиться только через имя класса и точку.
