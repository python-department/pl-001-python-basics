Установка интерпретатора Python

Требования к версии

Для успешного прохождения курса потребуется интерпретатор версии не ниже 3.12. Более ранние версии (3.11 и старше) не подходят.

Проверить установленную версию можно командой:

python --version
# или
python3 --version

В выводе должно быть, например, Python 3.12.x или выше.

Скачивание и установка интерпретатора

Windows

  1. Откройте раздел Python Releases for Windows на официальном сайте и скачайте Windows installer (64-bit) для версии 3.12 или новее.

  2. Запустите скачанный файл установки, например, python-3.12.x-amd64.exe.

  3. ВАЖНО: на первом экране установщика поставьте галочку «Add python.exe to PATH» (внизу окна). Без неё команды python и pip не будут доступны из терминала.

  4. Нажмите Install Now (либо Customize installation, если нужен нестандартный путь).

  5. После установки откройте новое окно PowerShell или «Командной строки» и проверьте, что интерпретатор и пакетный менеджер были установлены и добавлены в PATH:

    python --version
pip --version

    Если все сделано правильно, в результате выполнения этих команды в терминале будут напечатаны версии утилит.

Если забыли добавить в PATH

Запустите установщик повторно, выберите Modify и убедитесь, что включена опция добавления в PATH.

Или добавить путь в PATH можно вручную. Для этого перейдите в раздел «Изменение системных переменных сред» → «переменные среды». В переменную Path добавьте пути вида:

  • C:\Users\<Имя>\AppData\Local\Programs\Python\Python312\
  • C:\Users\<Имя>\AppData\Local\Programs\Python\Python312\Scripts\

После изменения PATH перезапустите терминал.

macOS

Вариант 1. Официальный установщик (рекомендуется для новичков)

  1. Откройте раздел Python Releases for macOS на официальном сайте и скачайте macOS 64-bit universal2 installer для версии 3.12 или новее.

  2. Запустите скачанный файл установки, например, python-3.12.x-macos11.pkg и пройдите шаги мастера установки.

  3. Откройте новый терминал и проверьте, что интерпретатор и пакетный менеджер были установлены и добавлены в PATH:

    python3 --version
pip3 --version

    Если все сделано правильно, в результате выполнения этих команды в терминале будут напечатаны версии утилит.

Вариант 2. Homebrew

ВАЖНО: Для выполнения этого варианта установки, на вашем mac должна быть установлена утилита Homebrew.

  1. Выполните установку интерпретатора с помощью следующей команды:

    brew install python@3.12

  2. Homebrew обычно сам добавляет ссылки в PATH. Если python3 не находится, добавьте в ~/.zshrc:

    export PATH="/opt/homebrew/opt/python@3.12/bin:$PATH"   # Apple Silicon
export PATH="/usr/local/opt/python@3.12/bin:$PATH"      # Intel

  3. Перезапустите терминал или выполните source ~/.zshrc.

Частые проблемы

Симптом Причина Решение
python: command not found / 'python' is not recognized Путь до интерпретатора не добавлен в PATH Добавьте путь в PATH (см. раздел вашей ОС) и перезапустите терминал
Установилась версия ниже 3.12 Старый пакет в репозитории или скачан не тот установщик Скачайте свежий установщик с python.org
python указывает на Python 2 В системе несколько интерпретаторов Используйте явную команду python3 / python3.12
