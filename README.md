# Программирование на языке Python: Основы

Семестровый курс посвящен изучению синтаксиса, основных конструкций и концепций языка программирования Python.

Для успешного прохождения курса вам потребуется интерпретатор Python не ниже версии 3.12. Мануал по скачиванию и установке интерпретатора можно найти [тут](./manuals/python-installation.md).
