# Программирование на языке Python: Основы

Семестровый курс посвящен изучению синтаксиса, основных конструкций и концепций языка программирования Python.

Для успешного прохождения курса вам потребуется выполнить следующие действия перед началом:

- Установить интерпретатор Python не ниже версии 3.12. Мануал по скачиванию и установке интерпретатора можно найти [тут](./manuals/python-installation/python-installation.md).
- Установить и настроить систему контроля версий Git. Мануал по скачиванию, установке и первичной настройке можно найти [тут](./manuals/git-installation/git-installation.md).
